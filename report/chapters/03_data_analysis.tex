\section{Dataset Overview \& Data Preprocessing Pipeline}
The competition dataset comprises:
\begin{itemize}
  \item \textbf{Training Set:} 2,494 research papers containing metadata fields: \texttt{id}, \texttt{title}, \texttt{venue}, \texttt{year}, \texttt{authors}, \texttt{doi}, and the ground-truth reading preference \texttt{Label} $\in \{1, 2, 3, 4, 5\}$.
  \item \textbf{Test Set:} 596 unrated candidate papers containing identical metadata attributes with hidden labels.
\end{itemize}

\subsection{Data Cleaning \& Text Normalization}
Rigorous data hygiene checks revealed several critical domain-specific anomalies that were addressed before modeling:
\begin{enumerate}
  \item \textbf{HTML Entity Decoding in Titles:} Numerous paper titles contained encoded HTML entities from scraping artifacts, such as \texttt{\&apos;} (single quote), \texttt{\&quot;} (double quote), \texttt{\&amp;} (ampersand), \texttt{\&lt;}, and \texttt{\&gt;}. Leaving these unescaped severely degrades both tokenization and dense transformer embeddings. All titles were processed via \texttt{html.unescape()} followed by whitespace regularization.
  \item \textbf{Missing Author Imputation:} Approximately $1.8\%$ of records lacked author metadata (primarily proceedings volumes and committee prefaces). Missing authors were imputed with empty strings, and the numerical feature \texttt{author\_count} was assigned to 0.
  \item \textbf{DOI Presence Flagging:} Approximately $18.5\%$ of records lacked a registered Digital Object Identifier (DOI). We engineered a binary indicator feature $\texttt{has\_doi} \in \{0, 1\}$ to capture official catalog registration status.
  \item \textbf{Publication Year Normalization:} Chronological values were coerced to numeric, with missing values imputed by the historical median (2020), and linearly normalized via $\text{year\_norm} = (\text{year} - 2000) / 30$.
\end{enumerate}

\begin{itemize}

  \item \textbf{Ratings 2--5 (Worthwhile Papers):} Total 1,591 papers (**$63.8\%$**), exhibiting a monotonic frequency decline: Rating 2 (514 papers, $20.6\%$), Rating 3 (438 papers, $17.6\%$), Rating 4 (367 papers, $14.7\%$), and Rating 5 (272 papers, $10.9\%$).
  \item $\implies$ \textbf{Modeling Implication:} Stage 1 of the pipeline faces an asymmetric classification challenge between negative instances ($36.2\%$) and positive instances ($63.8\%$), necessitating precise False Positive suppression.
\end{itemize}

\begin{prismbox}[title=\textbf{Critical Discovery: Severe Venue Skew in the Test Set}]
Table \ref{tab:venue_stats} reveals an acute structural distribution shift:
\begin{itemize}
  \item Venues specialized in Logic Programming and Non-Monotonic Reasoning (\texttt{lpnmr}, \texttt{iclp}) exhibit high worthwhile ratios ($74\% - 82\%$).
  \item Conversely, theoretical logic and hardware/software verification venues (\texttt{cav}, \texttt{lics}) exhibit low worthwhile ratios ($52\% - 54\%$).
  \item \textbf{The Test Trap:} Together, \texttt{cav} and \texttt{lics} account for $\mathbf{68.5\%}$ of all test instances (408 out of 596 papers)!
  \item A model lacking Out-Of-Fold Venue Target Encoding will over-recommend papers from \texttt{cav} and \texttt{lics}, leaking rating-1 papers into the shortlist and decimating $Q$.
\end{itemize}
\end{prismbox}

\section{Semantic Embedding Analysis via Sentence-BERT}
To capture latent semantic relationships beyond discrete vocabulary matching, we deployed \texttt{all-MiniLM-L6-v2} \cite{reimers2019sentence} to encode titles into 384-dimensional $L_2$-normalized dense vectors. An Interest Centroid $\vec{C}_{\text{high}}$ was computed by averaging embeddings of all training papers with $y \ge 4$. Cosine similarity to this centroid was evaluated for each publication:
\begin{equation}
  \text{Sim}(i) = \vec{v}_i \cdot \vec{C}_{\text{high}}
\end{equation}

\begin{figure}[!ht]
  \centering
  \includegraphics[width=0.92\linewidth]{figures/05_sentence_bert_semantic_insights.png}
  \caption{Semantic analysis of paper titles via Sentence-BERT: (Left) Cosine similarity distribution across ratings; (Right) 2D PCA projection of semantic space}
  \label{fig:sbert_insights}
\end{figure}

Figure \ref{fig:sbert_insights} provides a pivotal empirical finding:
\begin{itemize}
  \item Mean cosine similarity increases **strictly monotonically** across all 5 rating tiers:
    \begin{itemize}
      \item Rating 1: $0.3827 \pm 0.08$
      \item Rating 2: $0.4160 \pm 0.08$
      \item Rating 3: $0.4484 \pm 0.08$
      \item Rating 4: $0.4642 \pm 0.09$
      \item Rating 5: $\mathbf{0.5019} \pm 0.09$
    \end{itemize}
  \item The Spearman rank correlation reaches $\mathbf{0.2800}$ ($p < 10^{-40}$) and Pearson correlation achieves $\mathbf{0.2805}$.
  \item The PCA semantic manifold (right) visually demonstrates that rating-4 and rating-5 papers form tight clusters distinctly separated from rating-1 items.
\end{itemize}
