\section{Four Core Data Discoveries}

\subsection{Insight 1: The ASP \& Neuro-Symbolic Profile}
\begin{itemize}
  \item \textbf{Discovery:} The researcher is a dedicated domain expert in \textit{Answer Set Programming (ASP)} \cite{gebser2011potassco}, Non-Monotonic Reasoning, and Description Logics. Papers bridging deep learning and symbolic reasoning (\textit{Neuro-Symbolic AI}, \textit{Explainable AI}) receive outstanding preference scores.
  \item \textbf{Engineering Action:} We compute positive reference centroids for rating 5 ($\vec{C}_5$) and rating 4 ($\vec{C}_4$), alongside a negative centroid for rating 1 ($\vec{C}_1$). We engineer the directional semantic margin feature:
  \begin{equation}
    \text{Margin}(i) = \text{Cosine}(\vec{v}_i, \vec{C}_5) - \text{Cosine}(\vec{v}_i, \vec{C}_1)
  \end{equation}
\end{itemize}

\subsection{Insight 2: Deterministic Conference Metadata Suppression}
\begin{itemize}
  \item \textbf{Discovery:} Front matter entries (proceedings headers, editorial notes) constitute $100\%$ rating-1 instances. Allowing even a single proceedings entry into the top 30 positions severely degrades the DCG denominator, reducing Relevance $Q$.
  \item \textbf{Engineering Action:} We construct a deterministic rule-based filter: $\texttt{is\_proceedings} = 1$ when titles contain keywords such as \textit{"proceedings", "conference on", "preface", "workshop on"}, forcing predicted worthwhile probability to zero.
\end{itemize}

\subsection{Insight 3: High Author Affinity \& Co-Authorship Signal}
\begin{itemize}
  \item \textbf{Discovery:} Test authors exhibit a substantial $\mathbf{45.9\%}$ overlap with the training author base (648 unique co-authors). Papers co-authored by trusted domain figures consistently earn top ratings.
  \item \textbf{Engineering Action:} We compute Out-Of-Fold author statistics strictly within training folds:
    \begin{itemize}
      \item \texttt{author\_max\_rating}: Maximum historical rating earned by any co-author.
      \item \texttt{author\_mean\_rating}: Average historical rating of the paper's authors.
      \item \texttt{author\_paper\_count}: Historical publication frequency in the dataset.
    \end{itemize}
\end{itemize}

\subsection{Insight 4: Bayesian Venue Smoothing}
\begin{itemize}
  \item \textbf{Discovery:} While \texttt{cav} and \texttt{lics} represent $68.5\%$ of the test set, their worthwhile probability is only $52\% - 54\%$, far below \texttt{lpnmr} ($81.9\%$) and \texttt{iclp} ($74.3\%$).
  \item \textbf{Engineering Action:} We apply Bayesian target smoothing with prior weight $m = 5$:
    \begin{equation}
      S_{\text{venue}} = \frac{n_v \cdot \bar{y}_v + m \cdot \bar{y}_{\text{global}}}{n_v + m}
      \label{eq:bayesian_venue}
    \end{equation}
    providing a disciplined prior for candidate papers based on publication source.
\end{itemize}
