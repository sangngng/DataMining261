\section{Two-Stage Recommender Architecture}
To resolve the fundamental tension between Relevance ($Q$) and Coverage ($R$) governed by the Harmonic Mean metric, we propose a decoupled \textbf{Two-Stage Recommendation Pipeline}:

\begin{prismbox}[title=\textbf{Operational Workflow of the Two-Stage Architecture}]
\begin{enumerate}
  \item \textbf{Stage 1 --- High-Precision Binary Filtering Stage:}
    \begin{itemize}
      \item \textit{Objective:} Distinguish non-relevant literature ($y = 1$) from worthwhile publications ($y \ge 2$).
      \item \textit{Output:} Estimated probability of relevance: $p_i = P(y_i > 1 \mid \bm{x}_i)$.
      \item \textit{Action:} If $p_i < T^*$ (the calibrated decision threshold), candidate $i$ is pruned by setting $\text{priority}_i = 0$.
    \end{itemize}
  \item \textbf{Stage 2 --- Continuous Priority Ranking Stage:}
    \begin{itemize}
      \item \textit{Objective:} For surviving candidates ($p_i \ge T^*$), predict a continuous utility score to place ratings 4 and 5 at the foremost rank positions.
      \item \textit{Methodology:} Fuses GBDT regression with Multiclass Expected Gain estimation.
    \end{itemize}
\end{enumerate}
\end{prismbox}

\section{Application of Core Curriculum Paradigms}
Our architecture tightly integrates the substantive techniques taught in the Data Mining course:

\subsection{1. Semantic Topic Clustering (K-Means on Sentence-BERT)}
Rather than performing clustering on sparse TF-IDF bags-of-words, we fit a \textbf{K-Means Clustering} model ($K = 12$) directly within the 384-dimensional Sentence-BERT vector space:
\begin{itemize}
  \item Discovered clusters capture cohesive sub-fields: ASP Solvers \& Grounders, Neuro-Symbolic AI, Description Logics, SAT/SMT Solving, Model Checking, and Argumentation Frameworks.
  \item Euclidean distances to all 12 cluster centroids provide continuous topic proximity features for decision trees.
\end{itemize}

\subsection{2. Association Rules Mining (Apriori)}
Frequent itemset mining on high-priority papers uncovers co-occurrence affinities (such as \texttt{\{programming, using\}} $\to$ \texttt{answer} with $93.3\%$ confidence), serving as validation anchors for domain-specific feature engineering.

\subsection{3. Gradient Boosted Decision Tree Ensembles}
We deploy an ensemble of three premier GBDT frameworks:
\begin{itemize}
  \item \textbf{LightGBM} \cite{ke2017lightgbm}: Rapid training via GOSS and leaf-wise tree growth.
  \item \textbf{XGBoost} \cite{chen2016xgboost}: Regularized boosting utilizing second-order gradients.
  \item \textbf{CatBoost} \cite{prokhorenkova2018catboost}: Robust handling of categorical features with reduced target leakage.
\end{itemize}

\subsection{4. Learning-to-Rank \& Multiclass Expected Gain Formulation}
To directly optimize ranking metrics rather than generic mean squared error, we introduce:
\begin{enumerate}
  \item \textbf{LightGBM LambdaMART (\texttt{lambdarank}):} Direct ranking optimization \cite{burges2010ranknet} targeting discounted cumulative gain structures.
  \item \textbf{Multiclass Expected Gain Formulation:} A 5-class probability model estimating $\{P(y=k)\}_{k=1}^5$. Theoretical expected usefulness gain is computed by:
  \begin{equation}
    \mathbb{E}[\text{Gain}_i] = \sum_{k=1}^5 \frac{k - 1}{4} \cdot P(y_i = k \mid \bm{x}_i)
    \label{eq:expected_gain}
  \end{equation}
  The final hybrid priority score combines regression with expected gain:
  \begin{equation}
    \text{priority}_i = 
    \begin{cases}
      \hat{y}_i + 2.0 \cdot \mathbb{E}[\text{Gain}_i], & \text{if } P(y_i > 1 \mid \bm{x}_i) \ge T^* \\
      0.0, & \text{otherwise}
    \end{cases}
    \label{eq:priority_formula}
  \end{equation}
\end{enumerate}

\section{Out-Of-Fold Threshold Sweep Algorithm ($T^*$)}
To determine the optimal threshold $T^*$ without data snooping, we implement a fine-grained grid search across all Out-Of-Fold (OOF) predictions:

\begin{prismbox}[title=\textbf{Out-Of-Fold Threshold Calibration Algorithm}]
\begin{enumerate}
  \item Collect out-of-fold predictions: probabilities $\bm{p}_{\text{oof}} = [p_1, \dots, p_N]$ and scores $\bm{s}_{\text{oof}} = [s_1, \dots, s_N]$.
  \item Define search grid: $T \in [0.20, 0.80]$ with step size $\Delta T = 0.01$ (61 evaluation steps).
  \item For each threshold $T$:
    \begin{itemize}
      \item Generate test vector: $\bm{p}^{(T)} = \text{where}(\bm{p}_{\text{oof}} \ge T, \; \bm{s}_{\text{oof}}, \; 0.0)$.
      \item Compute $Q(T), R(T)$, and $\text{Score}(T)$ using official metric formulas \eqref{eq:harmonic_mean}.
    \end{itemize}
  \item Select $T^* = \arg\max_T \text{Score}(T)$. Empirical optima reliably converge within $T^* \in [0.53, 0.57]$.
\end{enumerate}
\end{prismbox}

\section{Decoupled Intra-List Consensus Re-ranking}
\label{sec:consensus_rerank}
A core theoretical insight derived during our competitive optimization is that monotonic transformations of priority scores across the entire list cannot alter rank order, whereas adjusting filtering thresholds alters the candidate count, risking Coverage $R$. 

To break through this trade-off, we introduced the \textbf{Decoupled Intra-List Consensus Re-ranking} paradigm:
\begin{enumerate}
  \item \textbf{Shortlist Freezing (Invariance of $R$):} We freeze the candidate shortlist $\mathcal{S}^* = \{i \mid P(y_i > 1 \mid \bm{x}_i) \ge T^*\}$, fixing $|\mathcal{S}^*| = 381$ publications ($63.93\%$ of the test set). Because the indicator set $\mathbb{I}(\text{priority}_i > 0)$ remains unchanged, Coverage $R$ is strictly preserved at its empirical optimum ($R \approx 0.8205$).
  \item \textbf{Consensus Disagreement Penalty (Maximization of $Q$):} For all surviving candidates $i \in \mathcal{S}^*$, their relative rank order is re-calibrated by penalizing prediction variance between distinct model architectures:
  \begin{equation}
    \text{priority}_i = \bar{s}_i - \lambda \cdot \left| s_i^{(V2)} - s_i^{(V4)} \right|
    \label{eq:consensus_rerank}
  \end{equation}
  where $\bar{s}_i = 0.5 \cdot s_i^{(V2)} + 0.5 \cdot s_i^{(V4)}$ denotes the master pure semantic ensemble score, and $\lambda = 0.20$ represents the calibrated consensus confidence coefficient.
  \item \textbf{Top-Rank Placement:} Because the DCG discount factor $w_r = 1/\log_2(r+1)$ decays rapidly (with Top 30 positions accounting for $16.07\%$ of total gain weight), rewarding inter-model consensus ($|s_i^{(V2)} - s_i^{(V4)}| \to 0$) promotes high-confidence 5-star publications (such as \textit{"NNV 2.0: The Neural Network Verification Tool"} and \textit{"Neural Network Robustness as a Verification Property"}) to the foremost ranks ($r \in [1, 10]$).
\end{enumerate}
Empirically, this decoupled formulation directly elevated our official Kaggle Leaderboard performance from $0.65008$ to our all-time peak of $\mathbf{0.65040}$ (\textbf{Rank 6 / 16}), proving that consensus-guided intra-list re-ranking yields genuine generalization benefits.


\section{Abstract-Augmented Scientific Transformer \& Surgical Cluster Apex (V26--V27)}
To transcend the title-only feature plateau, we formulated an Abstract-Augmented Scientific Transformer architecture operating over multi-source technical abstracts:

\begin{enumerate}
  \item \textbf{Multi-Source Academic Text Retrieval:} Using batch queries against OpenAlex and Semantic Scholar Graph APIs, we recovered full-text scientific abstracts for .44\%$ of the training set (,031$ publications) and .97\%$ of the test set ($ publications, reaching .4\%$ on \texttt{lics}).
  \item \textbf{Semantic Text Construction:} Candidate publications are represented as structured scientific prompts:
  \begin{equation*}
    \text{Prompt}_i = \text{Venue: } V_i \;\|\; \text{Topic: } C_i \;\|\; \text{Title: } T_i \;.\; T_i \;\|\; \text{Abstract: } A_i
  \end{equation*}
  integrating the 12 K-Means topic tags $ directly into the multi-head self-attention mechanism.
  \item \textbf{Dual-Zone Pairwise Ranking Loss:} Fine-tuning is governed by a composite loss uniting ordinal classification, smooth $ gain regression, and dual-zone pairwise margin constraints:
  \begin{equation}
    \mathcal{L} = \mathcal{L}_{\text{ord}} + 0.80 \mathcal{L}_{\text{gain}} + 0.50 \mathcal{L}_{\text{boundary}} + 0.70 \mathcal{L}_{\text{top}}
  \end{equation}
  where $\mathcal{L}_{\text{boundary}}$ enforces margin separation between rating $\ge 2$ and rating 1 items, while $\mathcal{L}_{\text{top}}$ penalizes rank inversions among top-tier publications ( \in \{4, 5\}$).
  \item \textbf{Surgical Cluster Boundary Apex (V26C):} Recognizing the \textit{Shortlist Invariance Principle}, our peak model (V26C) preserves .9\%$ of the proven V25B candidate set at Golden Budget $, applying a surgical boundary swap to only 4 borderline publications: demoting non-logic C9 items (supply chain contracts \#1298) and promoting C5 autonomous system verification (\#1814, \#1937).
\end{enumerate}

cd DataMining261\\
python3 -m venv .venv\\
source .venv/bin/activate\\
